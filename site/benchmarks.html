Benchmarks

How fast is MINK? Measured, not claimed.

Four small programs, written the plain way in MINK, Python, Go and Rust, timed on one PC. Python is the slowest, Go and Rust are faster than MINK, and the gap is stated below.

Results

Median whole-process time, in milliseconds. Lower is faster.

Recursive Fibonacci of 32 (function calls)

MINK14 ms
Python193 ms
Go11 ms
Rust7 ms

30 million iterations of integer arithmetic

MINK55 ms
Python2136 ms
Go20 ms
Rust19 ms

Sieve of Eratosthenes to 2 million (array reads and writes)

MINK56 ms
Python369 ms
Go14 ms
Rust13 ms

Longest Collatz chain under 100,000 (branches and division)

MINK61 ms
Python763 ms
Go19 ms
Rust12 ms

MINK ran 6 to 39 times faster than Python 3.11 and 1.3 to 3.9 times slower than Go (2 to 5 times slower than optimized Rust). Arrays are the weakest spot: every memory read and write is checked.

Method

How the numbers were made.

  • Four programs, each written the plain way in each language, not tuned: recursive Fibonacci of 32, 30 million iterations of integer arithmetic, a sieve of Eratosthenes to 2 million, and the longest Collatz chain under 100,000.
  • Each program was built once and run 7 times. The table shows the median of the whole process, from start to exit, output included. Very short runs are mostly start-up.
  • Every language had to print the same answer, or the run failed.
  • Machine: Intel(R) Core(TM) i9-14900K, Windows 11. Tools: mink 1.0.5, Python 3.11.9, go version go1.26.7 windows/amd64, rustc 1.97.1 (8bab26f4f 2026-07-14).
  • There was no C or C++ compiler on the test PC, so Go and Rust stand in as the compiled baselines. This page does not compare MINK with C or C++.
  • One PC, one suite. Treat these as a starting point, not a verdict. Run it yourself: python testapps/bench/run.py.

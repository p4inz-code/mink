Native Windows · one .exe · open source

Native Windows programs from small, readable source.

MINK is a programming language that compiles to one .exe. There is no runtime to install and no linker to set up. The compiler is written in Rust with no dependencies.

// Configuration: read a JSON document and print what it says.
mod json;

fn main() -> Int {
    let arena = rt_alloc(65536);
    let v = json_parse("{\"name\":\"mink\",\"workers\":4,\"debug\":true}", arena);
    if v == 0 {
        rt_print_str("bad json");
        return 1;
    }
    let name = json_as_str(arena, json_obj_get_val(arena, v, 0));
    rt_print_str(name);
    rt_str_free(name);
    rt_print_int(json_as_int(arena, json_obj_get_val(arena, v, 1)));
    let out = json_to_str(arena, v);
    rt_print_str(out);
    rt_str_free(out);
    rt_free(arena);
    return 0;
}

web_loopbackexamples/web_loopback
// A tiny web service on this PC: a server thread answers one request, the main thread asks it.
mod network;
mod http;
mod httpserver;
mod threads;

fn serve_one(arg: Ptr<Int>) -> Int {
    let sock = rt_mem_load(arg);
    let got = http_server_serve_default(sock);
    if got.0 == -1 {
        rt_str_free(got.1);
        return 1;
    }
    let copy = http_server_request_copy(got.1);
    let path = http_server_path(copy);
    rt_print_str(path);
    rt_str_free(path);
    http_server_respond_ok(got.0, "hello from mink");
    net_close(got.0);
    return 0;
}

fn main() -> Int {
    net_init();
    let sock = http_server_listen("127.0.0.1", 18080);
    if sock < 0 {
        rt_print_str("listen failed");
        return 1;
    }
    let arg = rt_alloc(8);
    rt_mem_store(arg, sock);
    let t = thread_spawn(serve_one, arg);
    let response = http_client_get_with("127.0.0.1", 18080, "/hello");
    let dup = rt_str_concat(response, "");
    let body = http_body(dup);
    rt_print_int(http_status_code(response));
    rt_print_str(body);
    rt_str_free(body);
    thread_join(t);
    http_server_close(sock);
    rt_free(arg);
    net_cleanup();
    return 0;
}

fn main() -> Int {
    let user = rt_sys_load_lib("user32.dll");
    if user == 0 {
        rt_print_str("could not load user32");
        return 1;
    }
    let metrics = rt_sys_get_proc(user, "GetSystemMetrics");
    // The argument list must hold at least four words.
    let args = rt_alloc(32);
    rt_mem_store(args, 0);
    let width = rt_sys_call(metrics, args, 1);
    rt_mem_store(args, 1);
    let height = rt_sys_call(metrics, args, 1);
    rt_print_str("screen:");
    rt_print_int(width);
    rt_print_int(height);
    rt_free(args);
    return 0;
}

Get started

Three steps, about a minute.

Install

Run the setup file, or npm install -g @p4inz-code/mink. It installs for your account and needs no administrator rights.

Write

Make hello.mink in any editor, or right-click, New, MINK Source File once setup has run.

Run or build

mink run hello.mink runs it. mink build hello.mink writes a hello.exe you can give to anyone.

How it compares

Where MINK fits next to Python and C++.

Files, icons and menus

.mink files get an icon, right-click Run, Check, Build and Edit, a New menu entry and a preview pane. Double-click only opens an editor. It never runs a file.

A real standard library

Files, JSON, CSV, SQLite, an HTTP client and server, threads, regular expressions, hashing, compression and more. You can also call Windows directly.

Setup that respects you

Installs for your account with no administrator rights, lists itself in Apps & features, keeps several versions side by side, and removes cleanly.

Open and credited

What MINK does not do yet

Honest limits.

  • Windows only. Windows 10 and newer. There is no Linux, macOS, browser or mobile target.
  • Young. Version 1.0.5. Expect rough edges, and tell us about them.
  • You manage memory. Strings and buffers are freed by hand, and leaks are reported when a program ends.
  • Speed is measured only on small programs. Four tests so far, on one PC, against Python, Go and Rust. There was no C or C++ compiler to compare with. See Benchmarks.
  • VS Code only. Other editors can use the language server directly. The extension is not on the Marketplace yet.
  • Unsigned. Signing is coming.

The full list is in KNOWN_LIMITATIONS.md.

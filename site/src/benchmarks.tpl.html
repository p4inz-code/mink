Benchmarks

How fast is MINK? Measured, not claimed.

Four small programs, written the plain way in MINK, Python, Go and Rust, timed on one PC. Python is the slowest, Go and Rust are faster than MINK, and the gap is stated below.

Results

Median whole-process time, in milliseconds. Lower is faster.

MINK ran {{RANGE_PY}} times faster than Python 3.11 and {{RANGE_GO}} times slower than Go (2 to 5 times slower than optimized Rust). Arrays are the weakest spot: every memory read and write is checked.

Method

How the numbers were made.

  • Four programs, each written the plain way in each language, not tuned: recursive Fibonacci of 32, 30 million iterations of integer arithmetic, a sieve of Eratosthenes to 2 million, and the longest Collatz chain under 100,000.
  • Each program was built once and run {{RUNS}} times. The table shows the median of the whole process, from start to exit, output included. Very short runs are mostly start-up.
  • Every language had to print the same answer, or the run failed.
  • Machine: {{CPU}}, Windows 11. Tools: {{MINK_VERSION}}, {{PY_VERSION}}, {{GO_VERSION}}, {{RUST_VERSION}}.
  • There was no C or C++ compiler on the test PC, so Go and Rust stand in as the compiled baselines. This page does not compare MINK with C or C++.
  • One PC, one suite. Treat these as a starting point, not a verdict. Run it yourself: python testapps/bench/run.py.

FAQ

Honest answers.

Why MINK exists, what it is like to use, and when you should pick another language.

Why would I use MINK instead of Go, Rust or Zig?

Mostly you should not, yet. Go and Rust are mature, faster on our benchmarks, and run on far more systems. Pick MINK if you want a single small Windows program from a tiny compiler with no linker, readable errors with explanations, and one fixed format, and you are happy with a young language. It suits people who want to see how a compiler turns source into an .exe, or who want to ship small Windows tools with no runtime.

Is it fast?

Faster than Python, slower than Go and Rust, on four small programs on one PC. The numbers and the method are on the Benchmarks page. We have not compared it with C or C++.

Does it have a garbage collector?

No. You free strings and buffers yourself, and a program that ends with any still alive stops with error E-R06 (exit code 106). This is the biggest thing to get used to. The Learn page has a worked example.

Can I build a website, or a web app, with it?

You can build the server side: the standard library has an HTTP server and client, SQLite and JSON, and the Examples include a web app in one .exe. MINK does not compile to JavaScript or WebAssembly, so it does not run in the browser. This website is built by a MINK program.

Can I build a Windows app with windows and buttons?

You can create real windows today by calling Windows directly, and the Examples include a clock window. MINK cannot yet hand Windows a callback, so there is no custom window procedure and clicks must be polled. Callbacks and a ui module are planned.

Does it run on Linux or macOS?

No. Windows 10 and newer only. Linux support is frozen.

Is it free? Can I use it at work?

Yes. It is under the Apache License 2.0: free for any use, including commercial. Copies must keep the copyright line and the NOTICE file, so the credit stays with its creator, Atharva Patil.

Why does Windows warn me about the setup file?

The files are not code-signed yet, so SmartScreen may ask you to confirm. Signing is coming. You can check a download against its SHA-256 in the download section.

Who makes it?

One person, Atharva Patil, at P4inz Interactive Labs. Other projects are on the portfolio. If something breaks, open an issue.

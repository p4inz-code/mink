## 2. New Capabilities Delivered

### 2.1 `stdlib/time.mink` — `time_strftime(ts, fmt)` + `time_strptime(s, fmt)`
- Pattern-based date formatting with directives: `%Y`, `%y`, `%m`, `%d`, `%H`, `%M`, `%S`, `%A`, `%a`, `%B`, `%b`, `%F`, `%T`, `%%`
- Pattern-based parsing (numeric directives + `%F`/`%T`/`%%`)
- `time_epoch(y, mo, d, h, mi, s)` for direct epoch construction
- Round-trip verified: `strptime` → `strftime` yields original input

### 2.2 `stdlib/assert.mink` — Assertion library
- `assert_true(cond)`, `assert_false(cond)`
- `assert_eq_int(a, b)`, `assert_ne_int(a, b)`
- `assert_eq_str(a, b)`, `assert_ne_str(a, b)`
- `assert_eq_float(a, b)`
- On failure: diagnostic to stderr, exit 1
- On success: silent (exit 0)

### 2.3 `mink test` CLI command — Test runner
- Discovers `fn test_*()` functions in source files
- Strips existing `main` to avoid conflicts
- Generates per-test wrapper with build+run isolation
- Reports PASS/FAIL per test + summary counts
- Compile errors reported inline

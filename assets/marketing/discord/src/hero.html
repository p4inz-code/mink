Native Windows programs from small, readable source.

One compiler, one .exe. No runtime to install.

> npm install -g @p4inz-code/mink
or the setup file, github.com/p4inz-code/mink
hello.mink
fn square(n: Int) -> Int {
    return n * n;
}

fn main() {
    let mut total = 0;
    for i in 1..6 {
        total = total + square(i);
    }
    rt_print_int(total);
}
> mink run hello.mink
